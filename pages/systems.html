Open SSH entries in PowerShell

Browsers can't start PowerShell on their own. A small helper lets SSH entries open PowerShell and run ssh user@host for you. Until it's set up, clicking an SSH entry copies that command so you can paste it.

  1. Download the SSH link helper.
  2. Right-click the downloaded file and choose Run with PowerShell. It installs for your Windows account only and doesn't need administrator rights.
  3. Turn on the switch below. The first time you click an SSH entry, your browser asks to open the link. Tick Always allow, then choose Open.

This setting is saved in this browser only. It needs the OpenSSH Client, which is built into Windows 10 and 11. Passwords are never put in links; ssh asks for the password in the PowerShell window. To remove the helper, run it with -Uninstall.

Open RDP entries in Remote Desktop

Browsers can't start Remote Desktop Connection on their own. A small helper lets RDP entries open it straight away, with the host and username filled in. Until it's set up, clicking an RDP entry copies the host so you can paste it into Remote Desktop Connection.

  1. Download the RDP link helper.
  2. Right-click the downloaded file and choose Run with PowerShell. It installs for your Windows account only and doesn't need administrator rights.
  3. Turn on the switch below. The first time you click an RDP entry, your browser asks to open the link. Tick Always allow, then choose Open.

This setting is saved in this browser only. It works on Windows 10 and 11, which include Remote Desktop Connection. Passwords are never put in links; Remote Desktop asks for the password when it connects. To remove the helper, run it with -Uninstall.

Remove system?

This removes the system and all of its saved credentials from Credentials Management.

  • It disappears from this list and from search results.
  • Its credentials can no longer be viewed or updated here.
  • The record is kept in the database for audit purposes. Only a database administrator can restore it.

This doesn't change anything on the system itself. Its servers and passwords keep working.
